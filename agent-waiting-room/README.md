# agent-waiting-room

This directory is the plugin itself. Install it from inside Claude Code (2.1.275 or later) with `/plugin install agent-waiting-room --marketplace mancyyu/agent-waiting-room`, or with the two terminal commands in the root README. The full documentation lives one level up, at the repository root:

- [README (English)](../README.md)
- [说明（中文）](../README.zh-CN.md)
- [Changelog](../CHANGELOG.md)

Specs and change notes for developers are in [docs/](docs/): `SPEC.md` (v0.2 behaviour), `SPEC-v0.3.md` (bilingual + public release), `adapters.md` (Codex / Cursor, untested), `CHANGES-backend.md`, `CHANGES-frontend.md`.

Run the tests from this directory with `node tests/run-tests.js`.
