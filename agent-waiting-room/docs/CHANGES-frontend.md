# 网页 v0.2 变更记录

这份文件记录 `public/hub.html` 相对 `docs/SPEC.md` 的偏离和补充。SPEC.md 本身没有改动。

验证结果（2026-11-05）：

- 演示模式（`?demo=1`，用预览外壳加 `python3 -m http.server`）：打开后约 4.5 秒弹出第一条横幅；游戏和放松遇到横幅都会暂停；五个标签页都能用；切到「只要提醒」后游戏和放松标签消失，刷新后仍然生效；14 天柱状图的柱高按比例画（15 个对应 140.6px，满格 16 个对应 150px）；控制台没有报错；375px 宽下每个标签页都没有横向滚动；深色模式和 `data-theme` 两种覆盖都正确。
- 本地模式：先用一个按 SPEC §6 写的假服务测了一遍，又在后端写好 `STATUS: DONE` 之后，用真服务（临时 `WAITING_ROOM_HOME`、端口 47919、`WAITING_ROOM_DRY_RUN=1`）配合 `bin/waiting-room hook prompt / stop / permission` 测了一遍。真服务的事件流水里能看到 `hub_open(auto)`、`banner_shown`、`back_click`、`game_start`、`game_end`；`turn_end` 的 `engaged` 为 true；设置页改的延迟和勿扰时段都写进了 `config.json`。每个请求都带了 `X-WR-Token`，所有 POST 的 `Content-Type` 都是 `application/json`，Origin 也都正确。

## 一、协调人追加的要求（2026-11-05）

1. **默认体验要轻。** 首屏只有状态面板和上次玩的那个小游戏。放松、我的数据、设置、关于都放在标签页里。文案缩短了，颜色只在状态上用。打开页面时不弹任何引导。
   - 每次打开都停在「小游戏」标签；只记住上次玩的是哪个游戏，不记住上次停在哪个标签。
   - SPEC 要求顶栏有「演示模式」标签，页面顶部还要显示「演示模式 · 数据为模拟」。为了少占首屏，两者合成顶栏里的一个标签「演示模式 · 数据为模拟」。
   - 说明条只在连不上本地服务、或缺少令牌时出现。
2. **`stale` 会话。** `stale` 为 true 时，卡片标签改成灰色的「可能已结束」，计时停住，改为显示「最后更新 HH:MM」和「N 分钟没有动静」，排到最后。这类会话不弹横幅，没有「知道了」按钮，也不算进顶部汇总。
   - 演示模式里，Cursor 那个会话的第一回合必定进入 stale，之后每回合有 30% 的概率进入。stale 持续 30 秒后，当作重新开了一回合。
3. **设置页加了一句说明**：「同一台电脑 5 分钟内只会自动打开一次等候室，所以连着提交几个任务时只会弹一次。」放在「自动打开等候页」下面。

## 二、偏离或补充 SPEC 的地方

**状态面板**

1. **「今天第几个回合」改成「第 N 回合」。** 会话里只有累计的 `turns`，没有按天的回合数。为了不写错，就不说「今天」。干活中和等你确认时显示 `turns + 1`，干完和出错时显示 `turns`。
2. **「出错了」的卡片也有「知道了」按钮。** SPEC 只写了 `needs_input` 和 `done`。出错同样需要用户确认，所以一起加上，点了同样调 `POST /api/seen`。
3. **排序细节。** 顺序是：等你确认 > 干活中 > 没看过的干完和出错 > 看过的 > stale。同一档里按 `createdAt` 固定排，不跟着服务端的顺序变。这样卡片不会每 1.5 秒跳一次位置。
4. **横幅只为打开页面之后发生的变化弹出。** 页面打开前就已经干完的会话，卡片上显示「刚干完」和「知道了」，但不弹横幅。`seenAt` 不早于 `statusChangedAt` 时视为看过，别的标签页点过「知道了」，这里的横幅也会撤下。

**提醒横幅**

5. **「回去看看」除了记 `back_click`，还会对横幅里的每个会话调 `POST /api/seen`**，然后关掉横幅，游戏或放松保持暂停。`back_click` 的 `sid` 取横幅里第一个会话。
6. **`banner_shown` 每个新提醒记一条，带上 `sid`。** 同时弹出两条提醒时，会记两条。
7. **「只要提醒」模式下，第二个按钮写「关掉横幅」**，因为这时没有游戏可以继续玩。
8. 三种状态的提示音不同：干完两声上行，等你确认三声，出错两声下行。

**上报**

9. **`game_end` 的口径。** `ms` 是实际玩的时间，不算暂停。萤火夜航和点灯的 `score` 是得分；成双的 `score` 是配成的对数（0–8）。中途放弃也记 `game_end`：成双中途重新洗牌，或者关掉页面（用 `keepalive` 的 fetch）都算。
10. **`relax_end` 在练习做完或中途点「结束这段」时记**，`ms` 是实际做的时间，不算暂停。换另一个练习时，前一个也会先记 `relax_end`。
11. `hub_open` 的 `source`：网址带 `?src=auto` 记 `auto`，带 `?src=link` 记 `link`，其他情况记 `manual`。

**两种运行方式**

12. **只有在 `localhost`、`[::1]` 或 IPv4 地址上打开时，才会请求 `/api/state`。** 其他域名不可能是本地服务，比如 claude.ai Artifact 的托管域名，这时直接进演示模式，一个请求都不发，控制台也就不会出现失败的请求。这和 SPEC「`/api/state` 请求失败就进演示模式」的结果一样，只是省掉了一次注定失败的请求。局域网和 VPN 地址都是 IPv4，所以手机访问不受影响。
13. **在本机打开却连不上服务时，进入演示模式，但会在后台每 5 秒用 GET 试一次 `/api/state`，连上就自动切回本地模式。** 用户的服务空闲退出后，重新打开旧标签页时不会一直停在假数据上。带 `?demo=1` 时不会重试。演示模式下不发任何写请求。
14. `/api/state` 返回 401（手机访问没带令牌）时进入演示模式，说明条提示用电脑上「设置 → 手机访问」里的完整地址打开。
15. 「导出匿名汇总」是普通 `<a href>`，带不了请求头，所以有令牌时链接写成 `/api/export?t=令牌`。

**演示模式的模拟器**

16. 第一个干完的会话固定是 Claude Code，在模拟器启动后 4.5 秒干完，保证 8 秒内有横幅。Codex 的第一回合固定在第 26 秒变成「等你确认」，让体验者早点看到橙色状态；之后都按 70% / 30% 随机。
17. **「等你确认」之后，同一回合接着干。** 用户点「知道了」或 20 秒后，会话回到「干活中」，再过 10–25 秒干完。SPEC 写的是「开始下一回合」。看到的效果一样，只是计时接着走，不从 0 开始，更像真实的 Claude Code。

**页面其他部分**

18. **设置页多了一行「浏览器通知」**，显示当前浏览器的通知权限，权限还没定时显示「允许浏览器通知」按钮。系统通知（`notify`）由后端发；浏览器通知只在页面处于后台、且这次不会发系统通知时才用。拿不到权限或嵌入环境不支持时，只显示状态文字。
19. 「我的数据」里「本周游戏局数」取 `days` 最后 7 天 `gamesPlayed` 之和；其余三个数字直接用 `totals`、`activeDays`、`firstSeen`。`days` 里缺的日子按 0 补齐。柱子下面有一个可以展开的表格，列出每天的具体数字，方便手机上没法悬停的人查看。
20. 本地模式下，「关于」放在设置页底部的折叠块里，标题是「关于这个插件：为什么做、怎么验证」。
21. 外部链接只有一个：调研报告，写成 `<a href target="_blank" rel="noopener">`。
22. 成双的牌背原来是蓝紫渐变，改成和萤火夜航一致的藏青色，避免常见的紫色渐变。CSS 里的颜色全部改成 `:root` 变量（灯泡、遮罩、横幅、Logo 都改了）。画布游戏里萤火虫本身的颜色仍写在脚本里，因为它在两种主题下都一样。

## 前端 v0.3 变更记录（2026-11-06）

1. 全页中英双语：字典 `STR = { zh, en }`，取字 `t(key, vars)` / `tn(key, n, vars)`；标记 `data-i18n`、`data-i18n-html`、`data-i18n-attr`；`applyLang()` 原地重绘（会话卡、横幅、游戏覆盖层、放松、我的数据、设置、隐私说明、`document.title`、`<html lang>`）。
2. 语言解析：`config.lang` 明确时按它；`auto` 时扫 `navigator.languages`，有以 `zh` 开头的就 zh，否则 en。`auto` 下每次加载 `POST /api/lang-hint`，演示模式不发。
3. 设置页新增「语言 / Language」三选项（自动 / 中文 / English），经 `/api/config` 保存，保存后立即重绘；老后端返回 400 时回退并提示。
4. 「关于」页在本地模式也显示：版本号、GitHub 链接、Star、报告问题、复制安装命令（剪贴板失败时退回只读文本框）。v0.2 放在设置页底部的说明折叠块移到这里。
5. Star 提示卡：活跃天数 ≥ 7 且未关闭过时显示在状态面板下方；关闭状态存 `localStorage`（`awr:star-nudge-dismissed`），演示模式不显示。
6. URL 选标签页：`?tab=status|games|relax|stats|settings|about` 或 `#tab=…`，非法值忽略，只要提醒模式下 games/relax 回退到默认页。
7. 文件 209,800 字节，仍是单文件 fragment；无外部脚本；无 alert/confirm/prompt。

## 前端 v0.4 变更记录（2026-11-06）

1. 首次自动打开的说明条 `#introStrip`：本地模式、网址带 `?src=auto`、`localStorage` 里没有 `awr:intro-seen` 时显示在标题下方；一显示就写入标记，之后不再出现。文案带当前 `delaySeconds`，切换语言时随 `applyLang()` 重画。按钮：知道了（关掉）、只要提醒别再自动打开（`saveConfig({ mode: 'remind' })`）、更多设置（跳到设置页）。演示模式和手动打开不显示。

3. `FALLBACK_VERSION` 改为 `0.4.0`。中英文案各加 9 个 key（`intro.*`、`set.notifyMin.*`、`toast.notifyMinRange`）。
